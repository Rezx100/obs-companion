# Architecture decision record

Electron + React is used instead of the proposed Tauri/Rust stack. This build environment has Node but no Rust or Windows toolchain; Electron permits a reproducible Windows NSIS cross-build and shares the Playwright worker runtime. Native privileges stay in the main process. The local UI is sandboxed and exposes only a typed IPC allowlist. Untrusted websites run in a separate ephemeral Playwright browser, with no preload, filesystem APIs, cookies or agent tools. SQLite uses the runtime's built-in node:sqlite, avoiding native ABI rebuilds.

OBS remains Mode A's recording engine. A dedicated profile and scene collection use a 3840×1080 atlas: screen left and camera right, each 1920×1080 at 30 fps. This is one synchronized recoverable MKV master, not two independently encoded source masters. Local extraction creates separate full-resolution files with re-encoding; the original is preserved. This explicit compromise needs encoder/hardware verification and uses more pixels than a normal 1080p recording. Audio track 1 is microphone only, track 2 optional desktop audio. Camera audio is muted. Audio is never silently doubled.

Mode B uses Playwright video and sampled visual frames as evidence, rather than claiming those browser videos are OBS recordings. Browser automation is read-only by policy: automatic clicks limited to disclosure widgets; other interactions must be explicitly selected. No forms, purchases, authentication or account mutations are automated. Recording and evidence work without cloud keys. AI analysis sends reviewed frame selections only. The optional speech adapter fixes the user's approved voice ID; no fallback voice is permitted.

SQLite journals project/job transitions and paid submission intent. An ambiguous provider timeout stays Unknown and retains its budget reservation. No automatic paid retry. Exports are staged, probed and atomically published under new filenames, preserving valid prior outputs. Main-process serialization and database constraints prevent duplicate work. Local MCP uses stdin/stdout and the current user's filesystem authority; it exposes typed project operations, no shell or network listener.

Installer is unsigned; no silent updater. Browser and FFmpeg dependencies are checked visibly. OBS is installed separately and is not redistributed. Windows acceptance is separate from Linux build and synthetic tests.
